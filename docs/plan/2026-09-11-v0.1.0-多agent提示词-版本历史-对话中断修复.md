# v0.1.0 多 Agent 提示词 + 版本历史 + 对话中断修复

> 状态: 已落地
> 日期: 2026-09-11
> 前置: v0.0.9(命令入对话 / 命令解释审核 / 多 Agent 管理中心)

## 1. 背景与需求

1. **多 Agent 监控可用化**: 上报接口已有,但缺少「给其他 AI 粘贴」的提示词;需要在「多Agent」菜单展示,并支持一键复制,使其他 AI 用 curl/代码上报进度,前端与 E-bot 均可知晓。
2. **版本变更历史**: 新增菜单,把历代版本功能简要展示在前端。
3. **对话异常中断**: 用户反馈 AI 刚回一句就被掐断;需定位并修复,沉淀文档。

## 2. 根因与修复(对话中断)

综合现象「有部分输出后静默结束」与代码路径,主要风险点:

1. **Vite 开发代理默认超时/缓冲**: `/api` SSE 长连接可能被代理提前断开;前端 `reader` 结束时若已有 chunk 不会报错,表现为「说到一半停了」。
2. **前端 SSE 缓冲切片**: 旧实现用 `lastIndexOf('\n\n')` 截 buf,与全量 `split` 解析耦合松散,半包边界不清晰。
3. **会话 id 未回填**: 后端新建会话后 `done` 未带 `conversation_id`,前端 `currentConvId` 可能长期为 0。
4. **agent 流收尾**: 收到首个 `result` 立即 `break`,未排空 stdout;进程异常时无正文也被硬失败。

修复:

- `web/vite.config.js`: `timeout`/`proxyTimeout` 设为 `0`,并设置 `x-accel-buffering: no`。
- `web/src/App.jsx`: 稳健 `parseSSE` 返回 `{events, rest}`;识别 `done.conversation_id`;连接中断时保留已输出并提示;error 时保留部分正文。
- `server/internal/handler/handler.go`: `done` 事件增加 `conversation_id`。
- `server/internal/agent/agent.go`: `result` 后继续排空 stdout;有正文时弱化进程错误。

## 3. 多 Agent 提示词

- 新增 `web/src/agentPrompt.js`:`buildAgentPrompt(origin)` 生成含字段表 + curl 示例的提示词。
- 「多Agent」页顶部 `prompt-card`,一键复制。
- `SystemPrompt` 增加「多 Agent 任务进度」查询说明,E-bot 可用 `curl` 查 `GET /api/agents/tasks`。

## 4. 版本菜单

- 新增 `web/src/changelog.js`(数组顶部追加新版本)。
- 顶栏「版本」tab 渲染卡片列表。

## 6. 验收

1. 打开「多Agent」→ 见提示词 → 复制 → 用 curl 上报一条 → 卡片出现并轮询更新。
2. 打开「版本」→ 见 v0.1.0 及更早条目。
3. 提问一个需要较长回答的问题 → 流式完整结束(出现 done),中途可用「终止」。
4. 问 E-bot「现在多 agent 任务进度」→ 能查并整理列表。

## 7. 本地验证建议

```bash
./scripts/start.sh
# 浏览器 http://localhost:5173
curl -sS -X POST 'http://127.0.0.1:5173/api/agents/tasks' \
  -H 'Content-Type: application/json' \
  -d '{"agent_type":"cursor","task_id":"demo-1","task_name":"demo","status":"running","progress":20,"message":"测试上报"}'
```
