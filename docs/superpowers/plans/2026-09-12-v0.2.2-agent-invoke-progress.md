# v0.2.2 Agent Invoke + Progress Implementation Plan

> **For agentic workers:** Execute task-by-task. Inline execution in this session (user: 开发吧).

**Goal:** Platform-orchestrated `@` multi-agent invoke, always-visible task progress, Chinese status/runtime labels, capsule settings UI.

**Architecture:** Backend parses mentions, plans tasks, parallel-invokes callees (queue if busy), streams isolated results, caller summarizes, async divider summaries with `exclude_from_context`. Frontend mention picker, quote bubbles, mini status, bottom progress bar, capsule toggles.

**Tech Stack:** Go/Gin, MySQL, React JSX, existing AskManaged SSE.

## Global Constraints

- No nested `@` this version
- Callee full answers only on caller; divider on callee only
- Never show `/api/agents/tasks` hint to users
- Status labels: 空闲中 / 忙碌中 / 错误 / 等待中
- Who calls summarizes asynchronously
