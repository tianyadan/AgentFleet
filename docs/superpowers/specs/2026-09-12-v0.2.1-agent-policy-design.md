# Design: v0.2.1 agent policy & engine colors

User approved via「沉淀开发文档，并更新代码吧」.

## Engine colors

- Claude: `#D97757` / soft peach bg
- Codex: `#10a37f` (OpenAI green)
- Agent(Cursor): `#6366f1` indigo

## Policy columns (defaults)

- allow_write=1, allow_network=1, allow_rm=0
- workspace_path='' → cross-workspace OK
- schedule_enabled=0, schedule_cron='', schedule_label=''

## Enforcement

1. Soft: policy text always in system prompt; reinforce every 10 user turns.
2. Hard: Classify post-filter Deny write/network/rm/out-of-workspace.
3. Schedule: cron runner calls AskManaged with 「按计划执行例行任务」.
