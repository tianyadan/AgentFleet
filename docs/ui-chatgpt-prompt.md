# ChatGPT 提问稿 — 数字员工后台管理 UI 设计图

帮我为「数字员工后台管理系统」设计多套不同风格的 UI 设计图（管理台 Dashboard）。

## 产品背景
这是一个「数字员工 / AI Agent」调度平台（代号 E-bot）。用户通过对话指挥多个 AI 智能体（Claude / Codex / Cursor 等引擎）完成真实开发任务，任务在授权工作区执行，带权限审核、团队编排、浏览器操作等能力。配套一个**后台管理台**，用于查看历史、统计、管理数字员工、编排协作项目等。

## 技术栈与现有视觉基调（供参考，欢迎在方案中升级）
- 前端：React + Vite；后端 Go(gin)；数据库 MySQL
- 现有配色：深色 slate 系（#0b1220 / #0f172a / #1e293b / #334155 背景层次），主点缀色天蓝 #38bdf8，辅助色：黄 #fbbf24（警告/审核）、绿 #22c55e（成功）、红 #ef4444（失败）、紫 #a78bfa
- 右上角有「管理台」入口；登录后进入后台

## 需要设计的后台页面（菜单）
1. **历史** — 会话/任务历史列表（分页、时间、引擎、状态）
2. **统计** — 数据看板（调用量、耗时、成功率、按引擎/按分组）
3. **数字员工管理** — 智能体列表 + 详情（引擎、人设提示词、权限、版本历史、分组「一键招聘」）
4. **项目协作** — 工作流/团队编排（把多个节点连成协作链路，节点有运行态）
5. **备忘录 / 常用密码 / 服务器** — 轻量记录类列表
6. **数据分析** — 更深度的图表分析
7. **版本** — 更新日志

2. 针对**「数字员工管理」列表页**和**「统计」看板页**给出更详细的布局描述（栅格、模块分区、交互）。
3. 每套方案给出可直接使用的**设计 token**（颜色/间距/圆角/阴影），方便我落地到 React+CSS。
