# v0.2.13 浏览器收尾提示、团队忙碌徽标与运行画布修复

## 1. 背景

browser-use 开启后易留僵尸页；团队占用与直接对话共用绿色徽标/金色忙碌文案易混淆；团队占用时管理页仍露出对话区；运行态 Canvas 控件样式与小图例未对齐编辑画布。

## 2. 开发目标

1. 允许浏览器时注入「用完网页及时关闭」提示（管理与编排共用策略块）
2. 智能体菜单：紫色徽标 = 团队编排忙碌数；绿色徽标仅直接运行
3. 团队占用中：管理页只展示任务进度，隐藏对话与发送
4. 去掉金色「忙碌中…任务标题」重复展示
5. 运行详情 Canvas 加减号与 MiniMap 对齐编辑画布

## 3. 实现范围

- `AgentPolicyBlock` + 设置 hint
- App 双徽标计数；ManagedAgents 占用态 UI
- `WorkflowRunGraph` 使用 `wf-flow` + MiniMap pannable/zoomable
