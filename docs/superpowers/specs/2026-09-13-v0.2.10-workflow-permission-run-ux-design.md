# v0.2.10 Design: workflow permission overlay + run UX

See `docs/plan/2026-09-13-v0.2.10-团队编排权限弹窗与运行态UX.md`.

## Root cause (bug 1)

Workflow `CreateAgentConversation` sets `user_ip='admin'`. Permission requests register with `ClientIP=admin`. `GET /api/permissions/pending` filters by browser `ClientIP`, so admin UI never sees workflow pending. Agent chat works because SSE fills `permQueue` directly.

## Fix

1. Admin JWT on pending → return all matching items (no IP filter).
2. `GET /api/admin/workflows/permission-pending` scoped to running node conversation IDs.
3. `WorkflowPermOverlay` + menu orange badge.
4. Rich card: risk low/mid/high + Chinese `meaning` (existing `explain`/`Reviewer`).

## Node auto_review

Graph `data.auto_review` boolean → `Perms.SetAuto(convID, true)` before Ask. Sensitive cmds still Ask via existing Classify/Reviewer.

## UX

- Menu label 团队编排; running-team green badge; pending orange badge.
- List: show 查看任务状态 for stopped/failed/interrupted (and active).
- Run view: graph nodes border success=green / failed=red; process auto-scroll; colored status chips.
