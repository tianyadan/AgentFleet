# v0.2.3 Design: WebFetch / Task Plan / Invoke Perm / Cmd UI

日期: 2026-09-12

## Root causes

1. **WebFetch**: Classify 返回 Ask；若策略/超时/未弹窗则表现为「网络策略」拒绝。已开 `allow_network` 时应直接 Allow。  
2. **进度 3 步**: `DefaultPlanSteps` 无委派时固定 3 条笼统步骤。  
3. **委托无弹窗**: `invokeOne` hook 使用被调方 `ConversationID`，调用方 Ask 的 SSE 按本方 conv 过滤，授权事件被丢弃直至超时拒绝。  
4. **命令 UI**: 展示结构不符合「色框命令 + 底栏含义 + 复制」。
