# v0.0.4 数据查询 + 超时容错 (E-bot)

> 状态: 已确认设计 / 待开发
> 创建: 2026-09-08
> 来源: NEW_FEATURE

## 1. 背景

v0.0.3 已完成:真流式、长对话、新建会话、IP 分组、人设「田浩文的赛博助理」+ 注入防御。v0.0.4 新增 3 项:

1. **超时容错**:AI 太长时间不返回会中断无结果,需延长请求超时 + 支持重试。
2. **数据查询模式**:新增一个可查数据库的模式。用户询问业务数据,分身用给定账号登录两个库,查询并返回。
   - 连接:`192.168.184.251:13306` / 用户 `tian-ai` / 密码 `12345678`
   - 可查库:两个(data-link、kfi-cloud)
   - 该功能作为**「项目」模块**存在,**名称=数据查询**;并入「全部授权工作区」这个项目模块,不独立出去。
3. **前端改名**:`🤖 Evan` → `E-bot`(作为"赛博助理")。

## 2. 开发目标

- 超时时间延长,超时后前端可**重试**。
- 新增「数据查询」项目模块,并入授权工作区体系,用户可问业务库数据,返回给前端。
- 前端标题/标识改为 `E-bot`。

## 3. 实现范围

- 本次实现:
  - agent 请求超时延长(如 180s→300s 或更长,可配置)。
  - 前端失败重试按钮/自动重试。
  - 「数据查询」模块:后端连远端 MySQL(只读),实现查库接口,供分身检索;前端并入工作区选择。
  - 名字改 E-bot。

- 本次暂不实现:
  - 完整自然语言→SQL(仍由 Agent 基于表结构写只读 SQL)。
  - 数据写入能力(只读)。
  - 多数据源管理界面。

## 4. 技术设计

- 数据库连接配置(数据查询模块):
  ```
  AVATAR_DATA_DB_DSN = "tian-ai:12345678@tcp(192.168.184.251:13306)/?parseTime=true&charset=utf8mb4"
  ```
  - 可达库(经探测):`data-link`(44 表)、`kfi-cloud`(154 表),及 ai-dev、kfi-cloud-dev。
  - **只读**:连接用户为查询账号;Agent 仅执行只读 SELECT/EXPLAIN,禁止写。
  - 在授权工作区体系中,「数据查询」作为一个项目(name=E-bot / 数据查询,path 标识为 `db://data-query` 或在 authorized_workspaces 加 type)。

- 数据表扩展:`authorized_workspaces` 增加 `type` 列(VARCHAR: `code` / `db`),及可选 `dsn`/`db_name`。
  - 种子新增:`(name='数据查询', type='db', dsn='tian-ai:...@tcp(...)', db_names='data-link,kfi-cloud')`。

- 接口:
  ```
  POST /api/question   (扩展) — 支持 data 查询模式(mode=data 或 workspace 指向数据查询项目)
    SSE: chunk / done / rejected / error(重试相关)
  新增:
  GET /api/workspaces — 返回含 type,前端展示「数据查询」与否
  (可加) POST /api/db/databases | /api/db/tables | /api/db/query 供分身检索
  ```

- 超时与重试:
  - agent: 超时默认 300s(可配 `AVATAR_TIMEOUT_SEC`)。
  - 前端: 流式读取失败/超时时,展示「重试」按钮,点击重发同一请求(新建会话或同一会话)。

- 关键规则:
  - 数据查询 = 只读;SQL 由 Agent 生成后仅执行只读语句。
  - 未授权库不可查(仅 data-link、kfi-cloud 等配置的库)。
  - 超时后已写入的 message 标记,支持重试。

## 5. 变更影响

原设计(v0.0.3):
- `authorized_workspaces` 仅 code 目录;无 DB 查询。
- agent 超时 180s;前端无重试。
- 前端名「Evan」。

新设计(v0.0.4):
- `authorized_workspaces` 增加 type + dsn + 数据查询项目。
- agent 超时延长 + 前端重试。
- 前端名「E-bot」。

影响:
- store SQL(workspaces 查询带 type)。
- handler 数据查询路由。
- agent 超时配置。
- 前端工作区下拉、重试 UI、标题。
