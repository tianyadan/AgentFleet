# 后台管理台 Kimi 风壳层改造（一期 A）

## 背景

管理台为快速迭代沿用暗蓝 slate 主题（`#0f172a` + 青强调色），且 `.app-admin` 限制 `max-width: 1100px` 居中，左侧菜单偏松（约 188px / 14px），导致两侧留白大、数字人对话等主内容区利用率低。前台助理（`PublicHome`）已对齐 Kimi 官方黑白风，后台观感割裂。

## 目标

1. 管理台视觉与前台助理同一套 Kimi 黑白 token（暗底、白主按钮）。
2. 布局改为典型后台壳：全宽 + 紧凑左侧菜单，主内容区吃满剩余宽度。
3. **一期只改壳与换色**，不重构业务交互；前台助理页面交互不动（品牌文案随全局改名）。
4. **产品对外名称**：全局由 `E-bot` 改为 **`agentFleet`**（展示大小写按此写法）。

## 范围

### In scope

- `web/src/App.jsx`：管理台顶栏 / 侧栏 / 主区容器结构与 class（折叠逻辑保留）。
- `web/src/App.css`：
  - 去掉管理台 `max-width: 1100px` 居中约束，改为全视口宽。
  - 在 `.app-admin` 挂 CSS 变量，壳层与可映射业务样式改用变量。
  - 侧栏收紧：展开约 **168px**，字号 **12px**，项高约 **32–34px**；折叠约 **52px** 仅图标。
  - 顶栏约 **48px**：品牌 + 版本；用户 + 退出。弱化「返回对话」（次要幽灵按钮或等价，不占视觉重心）。
- 业务页（数字人对话、数字人管理、对话审计、工作流、手册等）：**仅变量级换色**（背景 / 边框 / 文字跟随 token），不改布局与交互。
- **品牌文案替换（用户可见）**：
  - `web/index.html` `<title>` → `agentFleet`
  - 管理台顶栏标题 → `agentFleet` / `agentFleet 管理台`
  - 旧首页开场白、`agentPrompt.js`、`README.md` 等用户可见 `E-bot` → `agentFleet`（产品名）
- **运行时人设（后端）**：
  - 移除硬编码 `E-bot`；自称「`{数字员工名字} 数字员工`」（名字已含「数字员工」则不重复拼接）
  - 产品品牌名 `agentFleet` **不**写入模型人设自称
### Out of scope（二期及以后）

- 前台助理布局/交互重构（`PublicHome` 结构不动；若有可见「E-bot」字样一并改名）。
- 数字人对话内栏重构（`ma-list` 宽度策略、气泡/composer 对齐前台）——方案 B。
- 全后台组件级视觉重做、引入 Ant Design 整包换皮——方案 C。
- 亮色主题。
- **历史文档不强制改写**：`docs/plan/*`、`docs/superpowers/specs` 旧规格、`changelog.js` 已发布条目中的「E-bot」可保留为历史记述（避免篡改版本史）。代码注释中的「旧 E-bot 接口」类技术注释可酌情改为「兼容旧首页接口」，非必须全量替换。

## 布局

```
┌─ 顶栏 ~48px：agentFleet · 版本 | 用户 · 退出（返回对话弱化）─┐
├─ 侧栏 168↔52 ─┬─ 主内容 flex:1，内边距 16–20px ─────────┤
│  12px / 紧凑   │  业务页铺满剩余宽度（对话区优先受益）    │
│  图标 + 短文案 │                                            │
│  数字人 ▾     │                                            │
│   · 对话      │                                            │
│   · 管理      │                                            │
└───────────────┴────────────────────────────────────────────┘
```- 管理台高度目标：`min-height: 100vh`，主区尽量占满 `100vh - 顶栏`。
- 菜单分组（数字人子菜单）缩进收紧；折叠时隐藏子菜单文案，行为与现网一致。
- 移动端：侧栏仍可横向换行或叠放，不阻塞本期桌面优先目标。

## 色板（挂在 `.app-admin`）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0a0a` | 页面底 |
| `--surface` | `#141414` | 侧栏 / 卡片 / 输入面 |
| `--border` | `#2a2a2a` | 分割线、描边 |
| `--text` | `#f5f5f5` | 主文字 |
| `--muted` | `#8a8a8a` | 次要文字 |
| `--hover` | `#1f1f1f` | 菜单 hover |
| `--active` | `#222222`（可加左边细白条） | 当前菜单 |
| `--cta-bg` / `--cta-fg` | `#ffffff` / `#111111` | 主按钮 |
| 状态色 | 绿 / 橙 / 红语义色 | badge、成功/失败 |

管理台主色去掉大面积 slate 青蓝（不以 `#0f172a` / `#0284c7` / `#38bdf8` 作壳层主色）。引擎标签等小色点可保留辨识度。

`body` 在进入管理台时呈现与 `--bg` 一致的黑底；**不得**改写 `.app-public` 规则。

## 实现约束

- 不改后端 API、路由、菜单 id、权限与 SSE 行为。
- 优先 CSS / class 调整；避免为换肤大改 JSX 结构。
- 业务页硬编码色：能映射到变量的映射；映射成本过高的残留留给二期，不阻塞壳层合并。
- 验证：桌面宽度下管理台全宽、侧栏紧凑、对话主区明显变宽；前台 `/` 助理页视觉与行为无回归。

## 验收

1. 登录管理台后背景为 Kimi 黑底，侧栏紧凑、主区全宽。
2. 「数字人 → 对话」聊天区横向可用宽度较改前明显增加。
3. 前台助理页布局/交互无回归；浏览器标题与管理台品牌显示为 `agentFleet`。
4. 菜单切换、折叠、badge、登录/退出仍可用。
5. 用户可见产品名显示 `agentFleet`；模型人设自称「{名字} 数字员工」，不再出现 `E-bot`（历史 changelog / 旧 plan 除外）。

## 已确认决策

- 一期方案：**A（只改壳 + token 换色）**。
- 布局 §1、色板与范围 §2：用户已确认（2026-10-08）。
- 产品名：`E-bot` → **`agentFleet`**（2026-10-08）；历史文档与 changelog 旧条目不强制改写。
- 人设：去掉 E-bot，仅保留「{数字员工名字} 数字员工」（2026-10-08）；UI 主题按本文档一并实现。
