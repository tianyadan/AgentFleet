# v0.2.14 Design

**Parallel:** `runQueueWaves` — same wave concurrent `runNode`; mutex + `copyStringMap` for outputs.

**Folders:** `agent_folders` + `managed_agents.folder_id`; drag-drop via `POST /admin/agents/:id/folder`.

**Search:** client-side fuzzy filter on agent name.

**Workflow settings:** `graph.settings.allow_all_commands` → `SetAllowAllExceptRm`; rm still asks.

**Status:** `GET /admin/agents/:id/status` → ephemeral UI `role=status` dashed block; not DB / not model context.

**UI:** rename in settings; remove clear; canvas hint below flow; SVG + label in palette.
