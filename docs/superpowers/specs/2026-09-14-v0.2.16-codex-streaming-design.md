# v0.2.16 Design — Codex streaming

**Change:** `CodexAsk` uses `codex exec --json`, parses JSONL:

- `thread.started` → session/thread id
- `item.started|completed` `command_execution` → Activity (执行命令 · …)
- `item.completed` `agent_message` → text chunk
- `turn.completed` usage → RunMeta (input/output/cache)

Wire `onMeta` from `runManagedEngine` for Codex like Claude.
Fallback: if no JSON events, treat stdout as final text.
