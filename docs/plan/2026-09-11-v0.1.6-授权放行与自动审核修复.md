# v0.1.6 授权放行与 AI 自动审核修复

## 背景

1. 用户在权限弹窗点「同意」后，Bash 仍在 Claude 沙箱内执行，常被沙箱二次拦截。
2. 管理台智能体开启「AI 自动审核」后不生效：`POST /api/permissions/auto` 用客户端 IP 校验会话归属，而管理会话 `user_ip=admin`，导致 403，前端却仍把开关打成开启。

## 目标

- 明确授权（人工同意 / AI 自动放行）的 Bash：经 hook `updatedInput` 设置 `dangerouslyDisableSandbox: true`，本次命令不走沙箱隔离。
- 管理会话可正常开关 AI 自动审核；前端以接口成功为准更新 UI。

## 范围

- 修：`PermissionAuto` 归属校验、`avatar-hook` allow 输出、前端 `toggleAuto`、changelog。
- 不改：Classify 策略、权限弹窗 UI 布局。

## 技术设计

1. `ConversationOwner == clientIP || == "admin"` 才允许 SetAuto。
2. hook `emit("allow")` 对 Bash 合并原 `tool_input` + `dangerouslyDisableSandbox: true`。
3. `--settings` 注入 `"sandbox":{"allowUnsandboxedCommands":true}`，确保 escape hatch 可用。
4. `ManagedAgents` / `App` 的 `toggleAuto` 检查 `res.ok`，失败则回滚开关并提示。
