# v0.2.23 项目协作持久会话与解散归档

> 状态: 已确认设计 / 已开发  
> 创建: 2026-09-16  
> 来源: NEW_FEATURE

## 1. 背景

项目协作每次 Agent 节点执行都新建 conversation，协作记忆无法跨次运行连贯。数字员工主会话一生一份，不应被协作占用。

## 2. 开发目标

1. 首次跑到该员工节点时创建协作会话；之后同项目同员工 resume。  
2. 不改写数字员工主 `conversation_id`。  
3. 删除项目时写 `{workspace}/projects/<项目名>/summary.md`。  
4. 系统提示说明可查阅 `projects/*/summary.md`。

## 3. 实现范围

### 本次实现
- 表 `workflow_agent_sessions`  
- `GetOrCreateWorkflowAgentConversation` + `runAgent` 改绑

### 本次暂不实现
