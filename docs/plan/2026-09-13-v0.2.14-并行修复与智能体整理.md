# v0.2.14 并行修复、智能体文件夹与编排设置

## 1. 背景

Parallel 节点仅把后继入队，引擎仍串行 `runNode`，导致并行分支不同时跑。管理页缺少文件夹归类与搜索；编排缺全局「允许执行所有命令(rm 除外)」；编辑页节点按钮需 SVG；清空/改名入口需整理；需本地「状态」快照（不入上下文/DB）。

## 2. 开发目标

1. 真正并行执行 Parallel 后继（及队列中可并发的就绪节点）
2. 智能体文件夹 + 拖拽归类
3. 名称模糊搜索
4. 编排级设置：允许执行所有命令（rm 除外）
5. 编辑页提示下移；节点工具栏 SVG+文字
6. 移除「清空」
7. 改名迁入设置
8. 「状态」按钮：引擎适配快照，虚线分割展示，不入库、不进模型上下文

## 3. 技术要点

- `execute` / `executeFromWithSeed`：按波次并发 `runNode`，`outputs` 加锁合并
- `graph.settings.allow_all_commands` + Perms/HandlePermission 放行（rm 仍 Ask）
- `agent_folders` + `managed_agents.folder_id`（`db/migrate_v0.2.14.sql`）
- 状态：`GET /api/admin/agents/:id/status` 本地摘要，前端 role=`status` 虚线展示
