# v0.2.8 工作流 Canvas 体验与运行状态

## 1. 背景

v0.2.7 编排页可用，但 Controls/MiniMap 在深色主题下几乎不可见；缺少框选删除与撤销；职责提示为单行；列表页看不到团队运行状态与「查看任务状态」。

## 2. 开发目标

1. Controls 加减号在深色底上可见（白图标 / 深色按钮底）。  
2. MiniMap 按节点类型着色（流程图语义）；Agent 按 Claude/Codex/Cursor 引擎色；支持拖动 MiniMap 平移画布。  
3. 鼠标拖拽框选节点/边，Delete/Backspace 删除。  
4. Ctrl+Z 撤销，最多 5 步。  
5. 职责描述改为多行 textarea。  
6. 列表展示运行状态（空闲/忙碌中/等待中/错误等）及当前节点；运行中显示「查看任务状态」。

## 3. 实现范围

### 本次实现
- Canvas CSS + MiniMap/Controls 配置
- selectionOnDrag + deleteKeyCode + undo 栈
- NodePanel textarea
- 列表 API 附带 latest_run；前端状态条与跳转

### 本次暂不实现
- 完整命令面板快捷键体系
- MiniMap 自定义矢量形状组件（以颜色+圆角区分为主）

## 4. 技术设计

- `@xyflow/react`：`selectionOnDrag`、`panOnDrag={[1,2]}`、`MiniMap pannable`、`nodeColor`
- undo：变更前 `pushHistory({nodes,edges})`，上限 5
- `GET /admin/workflows` 每项附 `latest_run: {id,status,current_node_ids,fail_node_id,...}`

## 5. 变更影响

| 原 | 新 |
|----|----|
| Controls 白底白字 | 深色控件区 + 白图标 |
| MiniMap 灰块 | 类型/引擎着色 + 可拖动画布 |
| 无框选删除 | 拖选 + Delete |
| 无撤销 | Ctrl+Z ≤5 |
| 职责单行 | textarea |
| 列表无运行态 | 状态 + 当前节点 + 查看按钮 |
