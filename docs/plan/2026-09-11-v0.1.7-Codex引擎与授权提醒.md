# v0.1.7 Codex 引擎 / 待授权徽标 / Bark 提醒

## 背景

1. 管理台创建/使用 Codex 引擎智能体失败：`GenericAsk` 误用 `codex -p`（实为 profile），非交互执行应使用 `codex exec`。
2. 待授权命令仅弹窗，离开智能体页后不易察觉积压条数。
3. 需要复用本机 `~/bin/ai-notify.sh`（Bark），在出现新待授权时推送提醒；并提供可被 AI/脚本快速调用的封装。

## 目标

- Codex 引擎可稳定问答（`codex exec` + workspace-write + skip-git-repo-check）。
- 「智能体管理」菜单与列表展示待授权数量徽标。
- 每条新待授权推送 Bark 一次（同 request_id 去重）；`AVATAR_BARK_NOTIFY=0` 可关。

## 范围

- 改：`agent` Codex 调用、`AskManaged` 分支、权限 Register 后通知、前端徽标、changelog。
- 增：`scripts/notify-permission.sh`、config 项、简短单测。
- 不改：Claude hook 沙箱逻辑、自动审核策略本身。

## 技术设计

### CodexAsk
`codex exec --skip-git-repo-check -s workspace-write [-C dir] <prompt>`，Stdin 空，stdout 为最终回复。

### Bark
`scripts/notify-permission.sh "<摘要>"` → `~/bin/ai-notify.sh avatar warning "<摘要>" <epoch>`。
服务在人工等待路径异步 exec；失败仅日志。

### 徽标
`allPendingPerms().length` → 侧栏橙/琥珀徽标；列表项按该 agent 的 `permQueue.length`。
