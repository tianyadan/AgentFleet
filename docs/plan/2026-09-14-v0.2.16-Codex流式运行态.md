# v0.2.16 Codex 流式运行态

## 1. 背景

Codex 智能体对话此前整段缓冲后一次性输出，用户长时间看不到工具/命令进度。CLI 已支持 `codex exec --json` JSONL 事件。

## 2. 开发目标

Codex 运行时在对话页实时展示：工具/命令执行、正文增量，体验贴近 CLI，复用现有 activity/chunk/usage SSE。

## 3. 实现范围

- 本次：`CodexAsk` 改 `--json` 流式解析；命令/消息映射到 activity/chunk；usage/thread_id 落库回调
- 暂不：Codex 独立 UI；权限 hook 深度对接

## 4. 技术设计

- `codex exec --json` 读 stdout 行事件
- `item.started/completed` + `command_execution` → `onActivity`
- `agent_message` → `onChunk`
- `turn.completed.usage` / `thread.started` → `onMeta`（若接入）
- 解析失败回退缓冲模式

## 5. 变更影响

- `server/internal/agent/codex.go`（+ 解析测试）
- `invoke.go` 可为 Codex 接 onMeta
- changelog
