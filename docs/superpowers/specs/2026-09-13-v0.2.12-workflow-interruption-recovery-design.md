# v0.2.12 Design: workflow interruption recovery (in-process)

See `docs/plan/2026-09-13-v0.2.12-Workflow服务中断恢复.md`.

## Architecture note

Same process: no live 5s health poll during outage. Recovery = post-restart `waiting_recovery` + 3min auto Resume + manual resume for `interrupted`.

## Resume plan

1. Latest attempt per node.
2. Reuse if `success` && SelfCheck(output/artifacts paths).
3. needRerun = non-reusable executed nodes; propagate to successors of needRerun.
4. Roots = needRerun with no needRerun predecessor; `executeFromMany(roots)`.
5. Parallel success siblings stay reused.
