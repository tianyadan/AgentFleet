# v0.1.3 智能体管理

> 状态: 已落地
> 日期: 2026-09-11
> 前置: v0.1.2(管理台登录 / 版本展示)
> 来源: NEW_FEATURE

## 1. 背景

管理台需要统一创建、监督、对话本机智能体(Claude / Codex / Agent):规则提示词、多轮对话(≤20)、任务进度展示、清上下文/压缩/新对话。现有能力仅有被动 `agent_tasks` 上报与 E-bot Claude 流式问答,缺少「管理型智能体」注册表与专属对话通道。

## 2. 开发目标

| # | 目标 | 验收 |
|---|---|---|
| A | 管理台「智能体管理」菜单 | 登录后可见;一键创建选引擎 |
| B | CRUD + 重命名 + 规则描述 | 创建/改名/改规则/删除 |
| C | 唤起本机 CLI 多轮对话 | claude/codex/agent;SSE 输出;≤20 轮 |
| D | 状态/时长/输出 | 列表与对话页可见 idle/running/error、耗时 |
| E | 清对话 / 压缩上下文 / 新对话 | 三按钮可用 |
| F | 任务进度展示 | 拉取 `/api/agents/tasks`(外部上报),按 agent 过滤展示 |

## 3. 实现范围

- 本次实现:
  - 表 `managed_agents`;`conversations.agent_id`
  - JWT 管理 API:`/api/admin/agents*`
  - Claude 复用现有 Runner;Codex/Agent 通用 CLI Runner(伪流式兜底)
  - 管理台 UI:列表 + 对话区 + 规则 + 任务进度
- 本次暂不实现:
  - 运行前自动拆步(进度靠外部上报)
  - PID 长驻 / Claude `--resume`
  - Codex/Agent 与 Claude 同等 stream-json 能力保证

## 4. 技术设计

### 4.1 数据

```sql
CREATE TABLE managed_agents (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(128) NOT NULL,
  engine VARCHAR(32) NOT NULL,          -- claude | codex | agent
  bin_path VARCHAR(512) NOT NULL DEFAULT '',
  rules_prompt LONGTEXT NULL,
  status VARCHAR(32) NOT NULL DEFAULT 'idle', -- idle|running|error
  conversation_id BIGINT NULL,
  last_error TEXT NULL,
  last_run_ms INT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

ALTER TABLE conversations ADD COLUMN agent_id BIGINT NULL;
```

### 4.2 API(均需 JWT)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/agents` | 列表 |
| POST | `/api/admin/agents` | 创建 `{name,engine,bin_path?,rules_prompt?}` |
| PATCH | `/api/admin/agents/:id` | 重命名/改规则/改 bin |
| DELETE | `/api/admin/agents/:id` | 删除(+关联会话消息) |
| GET | `/api/admin/agents/:id/messages` | 当前对话消息 |
| POST | `/api/admin/agents/:id/ask` | SSE 提问 |
| POST | `/api/admin/agents/:id/clear` | 清空消息 |
| POST | `/api/admin/agents/:id/new` | 新对话(换 conversation) |
| POST | `/api/admin/agents/:id/compress` | 摘要压缩上下文 |

任务进度仍用公开 `GET /api/agents/tasks?agent_type=`(前端用 engine 或 managed id 字符串过滤 `agent_id`)。

### 4.3 对话与 Runner

- 多轮:组装最近 20 轮写入 prompt;超出截断
- Claude:`agent.Runner.AskStream`(可挂 hook)
- Codex/Agent:`exec` 本机 bin,优先尝试流式;失败则整段输出一次 chunk
- 默认 bin:`claude` / `codex` / `agent`,可被 `bin_path` 覆盖
- 压缩:用 Claude 对历史做摘要,清空后写入一条 system/assistant 摘要消息

### 4.4 前端

- 菜单 id:`agents` →「智能体管理」(替换原占位「Agent状态」文案)
- 左栏智能体列表 + 创建弹窗(选引擎)
- 右栏:对话(复用气泡/SSE 解析) + 规则编辑 + 任务进度 + 操作按钮
