# v0.1.5 智能体授权审核与体验

> 状态: 已落地
> 日期: 2026-09-11
> 前置: v0.1.4(智能体后台保活)
> 来源: FEATURE_CHANGE

## 1. 背景

管理型智能体已能后台跑 Claude,但未把 E-bot 已有的命令授权弹窗 / AI 含义风险 / 自动审核 / 已执行命令审计接到管理台 SSE。对话历史一次拉全;侧栏过窄;退出登录会丢后台会话入口;菜单无运行数量提示。

## 2. 开发目标

| # | 目标 | 验收 |
|---|---|---|
| A | 命令授权弹窗 | 拒绝/仅本次同意;展示 AI 含义与风险 |
| B | AI 自动审核开关 | 按会话开启后合规命令自动放行并留痕 |
| C | 已执行命令入对话 | 前端可见,历史可审计(落库 role=command) |

| G | 侧栏可折叠 | 管理台左菜单可收起加宽内容区 |

## 3. 实现范围

- 本次实现:复用 permission Hub;AdminAgentsAsk 转发 SSE;前端弹窗+自动审核;Messages 分页 API;徽标/折叠/登出保活+全局授权浮层
- 本次暂不实现:Codex/Agent 引擎同等 hook(仍主要 Claude);跨浏览器标签共享

## 4. 技术设计

### 4.1 授权

- `AdminAgentsAsk` 订阅 `Perms.Subscribe`,按 `conversation_id` 过滤转发 `permission_request` / `permission_auto` / `command` / `permission_resolved`
- 放行 Bash 时 `InsertMessage(role=command)` 便于审计
- 前端:自动审核开关调既有 `POST /api/permissions/auto`;decide 调既有 decide
- 面板隐藏或已登出时:`ManagedAgentPermOverlay` 全局浮层仍可点同意/拒绝

### 4.2 消息分页

```
GET /api/admin/agents/:id/messages?before_id=&limit=20
→ { items, total, conversation_id, has_more }
```

items 按 id 升序;before_id=0 取最新 20。

### 4.3 登出保活

- `ManagedAgentsPanel` 在 App 根常挂载(非仅 admin)
- `bgTokenRef`:有任务在跑时登出保留 token 供后台 API/SSE;登录后换新 token
- 登出不 `abort` 会话

### 4.4 UI

- 侧栏 `adminCollapsed` + 窄图标模式
- 菜单项徽章:`runningCount` 绿色圆点数字
