# Design: v0.1.7 Codex engine + pending auth badge + Bark

Approved 2026-09-11 (user: strategy A Bark).

## Decisions

1. Codex via `codex exec --skip-git-repo-check -s workspace-write -C <dir> <prompt>`; never `-p` as prompt.
2. Side menu amber badge = `allPendingPerms().length`; per-agent list badge = that agent's `permQueue.length`.
3. On human-wait `Register`, async `scripts/notify-permission.sh` → `~/bin/ai-notify.sh avatar warning …`; dedupe by request_id; `AVATAR_BARK_NOTIFY=0` disables.

## Non-goals

Codex permission bridge (Claude-style hooks), changing auto-review classifier.
