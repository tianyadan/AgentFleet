# v0.2.11 Design: workflow direct-upstream result handoff

See `docs/plan/2026-09-13-v0.2.11-团队编排节点结果传递.md`.

## NodeResult (output_json)

```json
{
  "status": "PASS|FAIL",
  "summary": "上游完成了什么（短）",
  "result": "交给下游的核心结果（受限长度）",
  "artifacts": [{"type":"file|image|doc","ref":"...","label":"..."}]
}
```

No full chat / command logs.

## Handoff

- Chain `A→B→C`: B gets A; C gets B only.
- Fan-in: all direct predecessors, each labeled `source_node_id`.
- Prompt mandates: prefer upstream; do not redo; supplement only if insufficient.
