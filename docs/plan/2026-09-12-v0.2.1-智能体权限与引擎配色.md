# v0.2.1 智能体引擎配色与权限策略

## 背景

管理台需按 Claude / Codex / Cursor(agent) 区分主题色；创建与设置需配置写入、联网、rm、工作区边界与定时执行，并防止长对话丢上下文后越权。

## 目标

1. 列表/标签按引擎官方风格配色。
2. 权限：写入 / 联网 / rm；定时（先开再编，预设+cron）；工作区（授权目录选择+手输，绑定后禁止跨区，默认不绑定可跨区）。
3. 策略写入系统提示，且每 10 轮用户消息再强化一次；工具授权层硬拦截。

## 技术要点

- `managed_agents` 增列；`AgentPolicy` 拼进 AskManaged 的 sys/question。
- `HandlePermissionRequest` 按 agent 策略 Deny。
- 定时：`robfig/cron` 进程内调度，触发时 AskManaged 固定调度提示。
- 工作区：绑定路径作为 CLI cwd + Classify roots。

## 非目标

浏览器原生绝对路径选文件夹（安全限制）；仅提供授权区下拉 + 手动路径。
