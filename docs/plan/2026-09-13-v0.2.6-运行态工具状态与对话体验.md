# v0.2.6 运行态工具状态与对话体验

## 1. 背景

管理台智能体运行时缺少 Cursor/Claude/Codex CLI 式的实时工具状态；发送后出现空 assistant 气泡难看；正文气泡过重；Codex 等生成的图片无法展示。

## 2. 开发目标

1. 运行中实时展示工具调用/命令执行状态（无文件 diff、无大段改码杂音）。  
2. 发送后显示银灰渐变 thinking（多词轮换，可幽默）；有正文后再渲染；assistant 无气泡、可一键复制。  
3. 支持 Markdown/本地路径图片展示（鉴权拉取）。

## 3. 实现范围

### 本次实现
- Claude stream-json 解析 `tool_use` → SSE `activity`
- Codex/Cursor：粗粒度「引擎执行中」+ 权限命令摘要进活动流
- 前端活动条、thinking、无气泡正文、复制、鉴权图片
- `GET /api/admin/agents/:id/file?path=` 受限读图

### 本次暂不实现
- Codex 全量 JSONL 工具流（依赖 CLI 能力，后续可增强）
- 非图片二进制附件预览

## 4. 技术设计

- `agent.Activity` + `AskStream`/`runManagedEngine` 回调 → SSE `activity`
- 摘要规则：Bash 显示短命令；Read/Edit/Write/Grep 仅状态词，不展开路径与 diff
- 前端：`sendQuestion` 不预插空 assistant；`thinkingPhrase` 轮换；首 chunk 再建消息
- `.msg.assistant .msg-body` 去背景；`AgentMarkdown` + blob 图片

## 5. 变更影响

| 原 | 新 |
|----|----|
| 仅文本 chunk | + activity 工具状态 |
| 空气泡占位 | thinking 渐变占位 |
| assistant 气泡底 | 纯文本流 + 复制 |
| 本地图裂图 | 鉴权 file API + blob |
