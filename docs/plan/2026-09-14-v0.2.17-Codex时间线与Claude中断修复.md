# v0.2.17 Codex 时间线与 Claude 会话污染修复

## 1. 背景

1. Codex 正文在对话框里无分隔累加，难读。
2. Codex 执行的命令只在运行态条闪过，未进对话时间线、未落库。
3. Claude 在 Ask 前会跑 `PlanConcreteSteps`（轻量拆分），却复用并污染主会话的 `engine_session_id`；下一轮 `--resume` 仍处「只输出 JSON 数组」上下文，于是只回一步计划 JSON 就结束。

## 2. 开发目标

1. Codex 对话以 `·` 时间线展示工作流（换行+标识）。
2. Codex 命令置灰写入时间线并入库（role=command），刷新可还原。
3. 修复 Claude：拆分/摘要等 noHook 调用不 resume、不写主会话 session。

## 3. 实现范围

- 本次：上述三项；changelog
- 暂不：Codex 权限 hook 对齐 Claude；改任务进度算法

## 4. 技术设计

- `runManagedEngine(noHook=true)`：resume=""，跳过 RememberEngineMeta
- Codex：`agent_message` → chunk 前缀 `\n· `；`command_execution` → SSE command + InsertMessage/recordCommand
- 前端：command/assistant 时间线样式（灰色命令行）

## 5. 变更影响

- invoke.go / codex.go / ManagedAgents.jsx / App.css / changelog
- `db/migrate_v0.2.17.sql`：一次性清空已污染的 Claude `engine_session_id`
